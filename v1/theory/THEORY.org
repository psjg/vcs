* Bootstrap

Everything in this directory is derived from this one file, including the
Makefile that derives it. So the first step cannot use the Makefile — and it
cannot assume Emacs either, which is not POSIX. The file is therefore a
polyglot: valid POSIX =sh= up to its first =exit=, and Org after it. The
=sh= preamble above is an Org source block (=:tangle no=) that holds a
tangler written in POSIX =awk=; the shebang runs it and then =make check=.
So the whole runbook, on any POSIX system with =make= and Nix, is

#+begin_src shell :tangle no
chmod +x THEORY.org && ./THEORY.org
#+end_src

Line two, =# -*- mode: org -*-=, is an Org comment and an Emacs mode cookie:
Emacs allows the cookie on the second line when the first is a shebang, so
the file opens in Org mode rather than Shell-script mode.

The awk tangler implements the subset of Org tangling this file uses:
=:tangle= on a block or inherited from a heading's =:header-args:LANG:=
property, =:tangle no=, directory creation, comma-escaped lines, Org's
rule of dropping a block's trailing blank lines and separating blocks of
one file by a blank line. It is not Org; it is checked against Org:
=make agree= tangles with both and diffs the trees, and they are
byte-identical (verified 2026-09-23 with mawk and dash). If a future
edit uses an Org feature the awk does not know, that check fails, which
is the intended failure. Spelled out, from a directory containing only
=THEORY.org=:

What is not derived, and why: =lake-manifest.json= is generated by Lake but
pins the Mathlib revision, so it is captured verbatim below (a generated
artefact, frozen); =flake.lock= is generated by Nix on first use and pins
nixpkgs — regenerate it with =nix flake lock= if it is missing;
=results/= holds model-checker output as evidence, which is data, not
source; and =.lake/= is the build cache.

* How to read and run this file

This is a literate runbook. Read top to bottom, it is the theory: prose, then
the definitions and theorems in the language that checks them. Tangled
(=C-c C-v t= in Emacs, or =make tangle=), it is a Lake project with a Nix
shell; =make check= re-verifies every claim. Exported (=C-c C-e l p=), it is
the paper.

Two seams are typed and one is not, and the file says which. Everything in
Lean shares one set of definitions: the theorems in [[*Worlds]] are the
theorems the executable code in [[*Exec — the seam to the implementation][Exec]] is checked against, and the
property tests in [[*Check — property tests on the same definitions][Check]] run on the same definitions. The TLA+ model in
[[*Sync — the dynamic half, model-checked][Sync]] is a different object (a protocol, not a structure); its seam to the
Lean model is data: traces. The cubical Agda in [[*Horn — the homotopical reading (interpretation, not part of the model)][Horn]] is an
/interpretation/ of the model, not a part of it, and is labelled so.

Conventions. Numbered claims keep the numbers of =FORMAL.md= so the two can
be read side by side; where this file and =FORMAL.md= disagree, this file
wins, because it is the one the machine reads.

* Worlds
:PROPERTIES:
:header-args:lean: :tangle V1/Worlds.lean
:END:

An event is a header (address, author, kind, shape, references, body hash)
and a body. The references, transitively closed, are a partial order $P$ on
events; content addressing makes the relation acyclic, so we do not model
hashes here and simply take a =PartialOrder=. Mathlib's class is used
directly: the seam between "our order" and "the standard theory" is an
instance resolution, not a translation.

A /world/ is an ideal of $P$: a downward-closed set of events. We write
worlds as predicates.

#+begin_src lean
import Mathlib.Order.Basic

namespace V1.Worlds
variable {α : Type} [PartialOrder α]

abbrev Pred (α : Type) := α → Prop

theorem pred_ext {S T : Pred α} (h : ∀ x, S x ↔ T x) : S = T :=
  funext (fun x => propext (h x))

/-- 2.1 -/
def IsIdeal (S : Pred α) : Prop := ∀ e r, S e → r ≤ e → S r
/-- ↓C -/
def Down (C : Pred α) (x : α) : Prop := ∃ c, C c ∧ x ≤ c
/-- ↑C -/
def Up (C : Pred α) (x : α) : Prop := ∃ c, C c ∧ c ≤ x
/-- order-convexity -/
def Convex (C : Pred α) : Prop := ∀ a b c, C a → C c → a ≤ b → b ≤ c → C b
/-- 2.6 -/
def adopt (S C : Pred α) : Pred α := fun x => S x ∨ Down C x
def drop  (S C : Pred α) : Pred α := fun x => S x ∧ ¬ Up C x
def diff  (T S : Pred α) : Pred α := fun x => T x ∧ ¬ S x
#+end_src

** 2.2 Ideals form a distributive lattice

The union and intersection of ideals are ideals, so ideals form a
sublattice of the powerset lattice, hence a distributive lattice; the
frontier (the antichain of maximal elements) is the normal form of a world.
The full statement, including Birkhoff's representation, is Mathlib's
=LowerSet= (see [[*Mathlib bridge]]). Here the two closure facts the rest of
the file needs.

#+begin_src lean
theorem ideal_union {S T : Pred α} (hS : IsIdeal S) (hT : IsIdeal T) :
    IsIdeal (fun x => S x ∨ T x) := by
  intro e r h hle
  cases h with
  | inl hs => exact Or.inl (hS e r hs hle)
  | inr ht => exact Or.inr (hT e r ht hle)

theorem ideal_inter {S T : Pred α} (hS : IsIdeal S) (hT : IsIdeal T) :
    IsIdeal (fun x => S x ∧ T x) := by
  intro e r ⟨hs, ht⟩ hle
  exact ⟨hS e r hs hle, hT e r ht hle⟩

theorem down_ideal (C : Pred α) : IsIdeal (Down C) := by
  intro e r ⟨c, hc, hec⟩ hre
  exact ⟨c, hc, le_trans hre hec⟩

theorem adopt_ideal {S : Pred α} (C : Pred α) (hS : IsIdeal S) : IsIdeal (adopt S C) :=
  ideal_union hS (down_ideal C)

theorem drop_ideal {S : Pred α} (C : Pred α) (hS : IsIdeal S) : IsIdeal (drop S C) := by
  intro e r ⟨hs, hnot⟩ hle
  refine ⟨hS e r hs hle, ?_⟩
  intro ⟨c, hc, hcr⟩
  exact hnot ⟨c, hc, le_trans hcr hle⟩
#+end_src

** 2.4 The difference of two worlds is convex

For ideals $S \subseteq T$ the difference $T \setminus S$ is order-convex.
Conversely, $S \cup D$ is an ideal exactly when everything strictly below
$D$ already lies in $S$ — and the machine proof showed that neither
convexity nor disjointness is needed for that converse.

#+begin_src lean
theorem diff_convex {S T : Pred α} (hS : IsIdeal S) (hT : IsIdeal T) :
    Convex (diff T S) := by
  intro a b c ⟨_, hnsa⟩ ⟨htc, _⟩ hab hbc
  refine ⟨hT c b htc hbc, ?_⟩
  intro hsb
  exact hnsa (hS b a hsb hab)

theorem union_ideal_iff {S D : Pred α} (hS : IsIdeal S) :
    IsIdeal (fun x => S x ∨ D x) ↔ (∀ x, Down D x → ¬ D x → S x) := by
  constructor
  · intro h x ⟨d, hd, hxd⟩ hnd
    have := h d x (Or.inr hd) hxd
    cases this with
    | inl hs => exact hs
    | inr hd' => exact absurd hd' hnd
  · intro h e r he hre
    cases he with
    | inl hs => exact Or.inl (hS e r hs hre)
    | inr hd =>
      by_cases hr : D r
      · exact Or.inr hr
      · exact Or.inl (h r ⟨e, hd, hre⟩ hr)
#+end_src

** 2.7 The cover laws

=adopt= and =drop= are inverse to each other exactly on the covers of the
lattice of ideals: (a) dropping what you just adopted returns you home iff
the change was absent and its dependencies present; (b) re-adopting what
you just dropped returns you home iff the change was present and nothing
else depended on it.

#+begin_src lean
theorem cover_a {S C : Pred α} (hS : IsIdeal S) (hC : Convex C) :
    drop (adopt S C) C = S ↔
      (∀ x, ¬ (C x ∧ S x)) ∧ (∀ x, Down C x → ¬ C x → S x) := by
  constructor
  · intro heq
    constructor
    · intro x ⟨hcx, hsx⟩
      have hx : drop (adopt S C) C x := by rw [heq]; exact hsx
      exact hx.2 ⟨x, hcx, le_refl x⟩
    · intro x hdx hncx
      have hx : drop (adopt S C) C x := by
        refine ⟨Or.inr hdx, ?_⟩
        intro ⟨c', hc', hc'x⟩
        obtain ⟨c, hc, hxc⟩ := hdx
        exact hncx (hC c' x c hc' hc hc'x hxc)
      rw [heq] at hx
      exact hx
  · intro ⟨hdisj, hbelow⟩
    apply pred_ext
    intro x
    constructor
    · intro ⟨hadopt, hnup⟩
      cases hadopt with
      | inl hs => exact hs
      | inr hd =>
        by_cases hcx : C x
        · exact absurd ⟨x, hcx, le_refl x⟩ hnup
        · exact hbelow x hd hcx
    · intro hsx
      refine ⟨Or.inl hsx, ?_⟩
      intro ⟨c, hc, hcx⟩
      exact hdisj c ⟨hc, hS x c hsx hcx⟩

theorem cover_b {S C : Pred α} (hS : IsIdeal S) (hC : Convex C) :
    adopt (drop S C) C = S ↔
      (∀ x, C x → S x) ∧ IsIdeal (fun x => S x ∧ ¬ C x) := by
  constructor
  · intro heq
    constructor
    · intro x hcx
      have hx : adopt (drop S C) C x := Or.inr ⟨x, hcx, le_refl x⟩
      rw [heq] at hx
      exact hx
    · intro e r ⟨hse, hnce⟩ hre
      refine ⟨hS e r hse hre, ?_⟩
      intro hcr
      have he : adopt (drop S C) C e := by rw [heq]; exact hse
      cases he with
      | inl hdrop => exact hdrop.2 ⟨r, hcr, hre⟩
      | inr hdown =>
        obtain ⟨c, hc, hec⟩ := hdown
        exact hnce (hC r e c hcr hc hre hec)
  · intro ⟨hsub, hideal⟩
    apply pred_ext
    intro x
    constructor
    · intro h
      cases h with
      | inl hdrop => exact hdrop.1
      | inr hdown =>
        obtain ⟨c, hc, hxc⟩ := hdown
        exact hS c x (hsub c hc) hxc
    · intro hsx
      by_cases hup : Up C x
      · obtain ⟨c, hc, hcx⟩ := hup
        by_cases hcx' : C x
        · exact Or.inr ⟨x, hcx', le_refl x⟩
        · exact absurd hc (hideal x c ⟨hsx, hcx'⟩ hcx).2
      · exact Or.inl ⟨hsx, hup⟩
#+end_src

** 2.8 The convex difference is the exact inverse

The laws above have preconditions because =adopt= and =drop= take a
/label/. With the /removed set/ as the delta they hold unconditionally: an
implementation that returns the removed set from =drop= and accepts it in
=adopt= never needs 2.7.

#+begin_src lean
theorem adopt_diff {S T : Pred α} (hT : IsIdeal T) (hsub : ∀ x, S x → T x) :
    adopt S (diff T S) = T := by
  apply pred_ext
  intro x
  constructor
  · intro h
    cases h with
    | inl hs => exact hsub x hs
    | inr hd =>
      obtain ⟨d, ⟨htd, _⟩, hxd⟩ := hd
      exact hT d x htd hxd
  · intro htx
    by_cases hsx : S x
    · exact Or.inl hsx
    · exact Or.inr ⟨x, ⟨htx, hsx⟩, le_refl x⟩

theorem drop_diff {S T : Pred α} (hS : IsIdeal S) (hsub : ∀ x, S x → T x) :
    drop T (diff T S) = S := by
  apply pred_ext
  intro x
  constructor
  · intro ⟨htx, hnup⟩
    by_cases hsx : S x
    · exact hsx
    · exact absurd ⟨x, ⟨htx, hsx⟩, le_refl x⟩ hnup
  · intro hsx
    refine ⟨hsub x hsx, ?_⟩
    intro ⟨d, ⟨_, hnsd⟩, hdx⟩
    exact hnsd (hS x d hsx hdx)
#+end_src

** 2.9 Path independence

Any enumeration of $T \setminus S$ that never lists an element before one of
its dependencies reaches $T$ by single-event adopts. This is the only sense
in which "reordering" exists: the lattice is thin, so there is nothing to
reorder.

#+begin_src lean
theorem step {S T : Pred α} (hS : IsIdeal S)
    (hsub : ∀ x, S x → T x) (e : α) (he : T e)
    (hmin : ∀ r, r ≤ e → r ≠ e → S r) :
    adopt S (fun x => x = e) = (fun x => S x ∨ x = e) ∧
    IsIdeal (fun x => S x ∨ x = e) ∧ (∀ x, (S x ∨ x = e) → T x) := by
  refine ⟨?_, ?_, ?_⟩
  · apply pred_ext
    intro x
    constructor
    · intro h
      cases h with
      | inl hs => exact Or.inl hs
      | inr hd =>
        obtain ⟨c, hce, hxc⟩ := hd
        subst hce
        by_cases hx : x = c
        · exact Or.inr hx
        · exact Or.inl (hmin x hxc hx)
    · intro h
      cases h with
      | inl hs => exact Or.inl hs
      | inr hx => exact Or.inr ⟨e, rfl, by rw [hx]⟩
  · intro a r ha hra
    cases ha with
    | inl hs => exact Or.inl (hS a r hs hra)
    | inr hae =>
      subst hae
      by_cases hr : r = a
      · exact Or.inr hr
      · exact Or.inl (hmin r hra hr)
  · intro x h
    cases h with
    | inl hs => exact hsub x hs
    | inr hx => rw [hx]; exact he

def MinFirst : List α → Prop
  | [] => True
  | e :: L => (∀ r, r ∈ L → ¬ r ≤ e) ∧ MinFirst L

def foldAdopt (S : Pred α) : List α → Pred α
  | [] => S
  | e :: L => foldAdopt (adopt S (fun x => x = e)) L

theorem path_independence {S T : Pred α} (hS : IsIdeal S) (hT : IsIdeal T)
    (hsub : ∀ x, S x → T x) (L : List α)
    (hmem : ∀ x, x ∈ L ↔ diff T S x) (hmf : MinFirst L) :
    foldAdopt S L = T := by
  induction L generalizing S with
  | nil =>
    apply pred_ext
    intro x
    constructor
    · exact hsub x
    · intro htx
      by_cases hsx : S x
      · exact hsx
      · exact absurd ((hmem x).2 ⟨htx, hsx⟩) (by simp)
  | cons e L ih =>
    have he : T e := ((hmem e).1 (by simp)).1
    have hmin : ∀ r, r ≤ e → r ≠ e → S r := by
      intro r hre hne
      by_cases hsr : S r
      · exact hsr
      · have hr : r ∈ e :: L := (hmem r).2 ⟨hT e r he hre, hsr⟩
        cases List.mem_cons.mp hr with
        | inl h => exact absurd h hne
        | inr h => exact absurd hre (hmf.1 r h)
    obtain ⟨heq, hideal, hsub'⟩ := step hS hsub e he hmin
    show foldAdopt (adopt S (fun x => x = e)) L = T
    rw [heq]
    apply ih hideal hsub'
    · intro x
      constructor
      · intro hx
        have hx' : x ∈ e :: L := List.mem_cons_of_mem e hx
        obtain ⟨htx, hnsx⟩ := (hmem x).1 hx'
        refine ⟨htx, ?_⟩
        intro h
        cases h with
        | inl hs => exact hnsx hs
        | inr hxe => subst hxe; exact hmf.1 x hx (le_refl x)
      · intro ⟨htx, hn⟩
        have hnsx : ¬ S x := fun hs => hn (Or.inl hs)
        have hx : x ∈ e :: L := (hmem x).2 ⟨htx, hnsx⟩
        cases List.mem_cons.mp hx with
        | inl h => exact absurd (Or.inr h) hn
        | inr h => exact h
    · exact hmf.2

* Components
:PROPERTIES:
:header-args:lean: :tangle V1/Components.lean
:END:

Pending events (everything above the recorded world) form an up-set, and
the connected components of the dependency graph restricted to them are
convex. So =record=, which offers one change per component (ADR-0007),
already produces convex changes — provided components are taken over
dependencies, never over links. Here $\le$ is the reflexive–transitive
closure of the dependency relation, so that a chain witness is available.

#+begin_src lean
namespace V1.Components
variable {α : Type} (dep : α → α → Prop)

inductive Path : α → α → Prop
  | refl (a : α) : Path a a
  | step {a b c : α} : dep a b → Path b c → Path a c

inductive Conn (Q : α → Prop) : α → α → Prop
  | refl {a : α} : Q a → Conn Q a a
  | fwd {a b c : α} : Q a → Q b → dep a b → Conn Q b c → Conn Q a c
  | bwd {a b c : α} : Q a → Q b → dep b a → Conn Q b c → Conn Q a c

def UpSet (Q : α → Prop) : Prop := ∀ a b, Q a → Path dep a b → Q b

theorem path_conn {Q : α → Prop} (hQ : UpSet dep Q) {a b : α}
    (ha : Q a) (p : Path dep a b) : Conn dep Q a b := by
  induction p with
  | refl a => exact Conn.refl ha
  | @step x y z hxy _ ih =>
    have hy : Q y := hQ x y ha (Path.step hxy (Path.refl y))
    exact Conn.fwd ha hy hxy (ih hy)

/-- 2.12 -/
theorem component_convex {Q : α → Prop} (hQ : UpSet dep Q) {a b c : α}
    (ha : Q a) (_hc : Q c) (_hac : Conn dep Q a c)
    (hab : Path dep a b) (_hbc : Path dep b c) :
    Q b ∧ Conn dep Q a b :=
  ⟨hQ a b ha hab, path_conn dep hQ ha hab⟩

end V1.Components

* Text
:PROPERTIES:
:header-args:lean: :tangle V1/Text.lean
:END:

The text materialiser, modelled intrinsically. A Fugue node is its path
from the root, a list of (side, key) steps; reading order is the in-order
traversal, defined directly on paths. Because the order is a property of
two paths alone, it is the same in every world: $M(S)$ is the restriction
of one global order to the live atoms of $S$ (3.3a). Keys are any linear
order; the instance below is the bridge.

#+begin_src lean
import Mathlib.Order.Basic

namespace V1.Text

class Key (K : Type) where
  lt : K → K → Prop
  irrefl : ∀ a, ¬ lt a a
  trans : ∀ {a b c}, lt a b → lt b c → lt a c
  total : ∀ a b, lt a b ∨ a = b ∨ lt b a
  deq : DecidableEq K

instance [LinearOrder K] : Key K where
  lt := (· < ·)
  irrefl := lt_irrefl
  trans := lt_trans
  total := lt_trichotomy
  deq := inferInstance

variable {K : Type} [Key K]
attribute [instance] Key.deq

inductive Side | L | R
  deriving DecidableEq

abbrev Step (K : Type) := Side × K
abbrev Path (K : Type) := List (Step K)

def stepLt (x y : Step K) : Prop :=
  (x.1 = Side.L ∧ y.1 = Side.R) ∨ (x.1 = y.1 ∧ Key.lt x.2 y.2)

def lt : Path K → Path K → Prop
  | [], [] => False
  | [], y :: _ => y.1 = Side.R
  | x :: _, [] => x.1 = Side.L
  | x :: xs, y :: ys => if x = y then lt xs ys else stepLt x y

theorem stepLt_irrefl (x : Step K) : ¬ stepLt x x := by
  intro h
  rcases h with ⟨h1, h2⟩ | ⟨_, h2⟩
  · rw [h1] at h2; cases h2
  · exact Key.irrefl _ h2

theorem stepLt_trans {x y z : Step K} (h1 : stepLt x y) (h2 : stepLt y z) : stepLt x z := by
  rcases h1 with ⟨a1, b1⟩ | ⟨a1, b1⟩ <;> rcases h2 with ⟨a2, b2⟩ | ⟨a2, b2⟩
  · rw [b1] at a2; cases a2
  · exact Or.inl ⟨a1, a2 ▸ b1⟩
  · exact Or.inl ⟨a1 ▸ a2, b2⟩
  · exact Or.inr ⟨a1.trans a2, Key.trans b1 b2⟩

theorem stepLt_total (x y : Step K) : stepLt x y ∨ x = y ∨ stepLt y x := by
  obtain ⟨sx, kx⟩ := x; obtain ⟨sy, ky⟩ := y
  cases sx <;> cases sy
  · rcases Key.total kx ky with h | h | h
    · exact Or.inl (Or.inr ⟨rfl, h⟩)
    · exact Or.inr (Or.inl (by rw [h]))
    · exact Or.inr (Or.inr (Or.inr ⟨rfl, h⟩))
  · exact Or.inl (Or.inl ⟨rfl, rfl⟩)
  · exact Or.inr (Or.inr (Or.inl ⟨rfl, rfl⟩))
  · rcases Key.total kx ky with h | h | h
    · exact Or.inl (Or.inr ⟨rfl, h⟩)
    · exact Or.inr (Or.inl (by rw [h]))
    · exact Or.inr (Or.inr (Or.inr ⟨rfl, h⟩))

theorem lt_irrefl : ∀ p : Path K, ¬ lt p p
  | [] => fun h => h
  | x :: xs => by
    intro h
    simp only [lt, if_pos rfl] at h
    exact lt_irrefl xs h

theorem lt_trans : ∀ {p q r : Path K}, lt p q → lt q r → lt p r
  | [], [], _, h1, _ => (h1 : False).elim
  | [], y :: ys, [], h1, h2 => by
    simp only [lt] at h1 h2; rw [h1] at h2; cases h2
  | [], y :: ys, z :: zs, h1, h2 => by
    simp only [lt] at h1 h2 ⊢
    by_cases hyz : y = z
    · rw [← hyz]; exact h1
    · rw [if_neg hyz] at h2
      rcases h2 with ⟨_, h⟩ | ⟨h, _⟩
      · exact h
      · rw [← h]; exact h1
  | x :: xs, [], [], h1, h2 => (h2 : False).elim
  | x :: xs, [], z :: zs, h1, h2 => by
    simp only [lt] at h1 h2 ⊢
    by_cases hxz : x = z
    · rw [← hxz] at h2; rw [h1] at h2; cases h2
    · rw [if_neg hxz]; exact Or.inl ⟨h1, h2⟩
  | x :: xs, y :: ys, [], h1, h2 => by
    simp only [lt] at h1 h2 ⊢
    by_cases hxy : x = y
    · rw [hxy]; exact h2
    · rw [if_neg hxy] at h1
      rcases h1 with ⟨h, _⟩ | ⟨h, _⟩
      · exact h
      · rw [h]; exact h2
  | x :: xs, y :: ys, z :: zs, h1, h2 => by
    simp only [lt] at h1 h2 ⊢
    by_cases hxy : x = y <;> by_cases hyz : y = z
    · subst hxy; subst hyz
      rw [if_pos rfl] at h1 h2 ⊢; exact lt_trans h1 h2
    · subst hxy
      rw [if_pos rfl] at h1; rw [if_neg hyz] at h2 ⊢; exact h2
    · subst hyz
      rw [if_neg hxy] at h1; rw [if_pos rfl] at h2; rw [if_neg hxy]; exact h1
    · rw [if_neg hxy] at h1; rw [if_neg hyz] at h2
      have hxz : x ≠ z := by
        intro e; subst e
        exact stepLt_irrefl x (stepLt_trans h1 h2)
      rw [if_neg hxz]; exact stepLt_trans h1 h2

theorem lt_total : ∀ p q : Path K, lt p q ∨ p = q ∨ lt q p
  | [], [] => Or.inr (Or.inl rfl)
  | [], y :: ys => by
    simp only [lt]
    cases h : y.1
    · exact Or.inr (Or.inr rfl)
    · exact Or.inl rfl
  | x :: xs, [] => by
    simp only [lt]
    cases h : x.1
    · exact Or.inl rfl
    · exact Or.inr (Or.inr rfl)
  | x :: xs, y :: ys => by
    simp only [lt]
    by_cases hxy : x = y
    · subst hxy; rw [if_pos rfl, if_pos rfl]
      rcases lt_total xs ys with h | h | h
      · exact Or.inl h
      · exact Or.inr (Or.inl (by rw [h]))
      · exact Or.inr (Or.inr h)
    · rw [if_neg hxy, if_neg (Ne.symm hxy)]
      rcases stepLt_total x y with h | h | h
      · exact Or.inl h
      · exact absurd h hxy
      · exact Or.inr (Or.inr h)

/-- 3.4 address independence -/
def relabel (f : K → K) : Path K → Path K := List.map (fun s => (s.1, f s.2))

theorem lt_relabel (f : K → K) (hf : ∀ a b, Key.lt a b → Key.lt (f a) (f b))
    (hinj : ∀ a b, f a = f b → a = b) :
    ∀ p q : Path K, lt p q → lt (relabel f p) (relabel f q)
  | [], [], h => (h : False).elim
  | [], y :: ys, h => by simp only [lt, relabel, List.map] at h ⊢; exact h
  | x :: xs, [], h => by simp only [lt, relabel, List.map] at h ⊢; exact h
  | x :: xs, y :: ys, h => by
    simp only [lt, relabel, List.map] at h ⊢
    by_cases hxy : x = y
    · subst hxy; rw [if_pos rfl] at h; rw [if_pos rfl]
      exact lt_relabel f hf hinj xs ys h
    · rw [if_neg hxy] at h
      have hne : (x.1, f x.2) ≠ (y.1, f y.2) := by
        intro e
        apply hxy
        have e1 : x.1 = y.1 := (Prod.mk.inj e).1
        have e2 : f x.2 = f y.2 := (Prod.mk.inj e).2
        obtain ⟨sx, kx⟩ := x; obtain ⟨sy, ky⟩ := y
        simp only at e1 e2
        rw [e1, hinj _ _ e2]
      rw [if_neg hne]
      rcases h with ⟨a, b⟩ | ⟨a, b⟩
      · exact Or.inl ⟨a, b⟩
      · exact Or.inr ⟨a, hf _ _ b⟩

/-- a text world: which atoms exist and which are killed -/
structure World (K : Type) where
  present : Path K → Prop
  killed  : Path K → Prop

def live (W : World K) (p : Path K) : Prop := W.present p ∧ ¬ W.killed p
def before (W : World K) (p q : Path K) : Prop := live W p ∧ live W q ∧ lt p q

/-- 3.3a: the order of two atoms is the same in every world where both are live -/
theorem before_stable (W W' : World K) {p q : Path K}
    (hp : live W' p) (hq : live W' q) (h : before W p q) : before W' p q :=
  ⟨hp, hq, h.2.2⟩

end V1.Text

* Moves
:PROPERTIES:
:header-args:lean: :tangle V1/Moves.lean
:END:

A move of an atom carries a key and a destination path; in a world the
move with the highest key wins. The winner exists for a nonempty set, is
unique up to key, and depends only on /which/ moves are present, not on
the order in which they arrived — so placement is a function of the world
(I10). This is the one op that changes a path after capture, and therefore
the one place where 3.3a weakens to "same moves of both atoms".

#+begin_src lean
import Mathlib.Order.Basic

namespace V1.Moves

class Key (K : Type) where
  lt : K → K → Prop
  irrefl : ∀ a, ¬ lt a a
  trans : ∀ {a b c}, lt a b → lt b c → lt a c
  total : ∀ a b, lt a b ∨ a = b ∨ lt b a

instance [LinearOrder K] : Key K where
  lt := (· < ·)
  irrefl := lt_irrefl
  trans := lt_trans
  total := lt_trichotomy

variable {K P : Type} [Key K]

structure Move (K P : Type) where
  key : K
  dest : P

def keyLe (m m' : Move K P) : Prop := Key.lt m'.key m.key ∨ m'.key = m.key

def Winner (l : List (Move K P)) (m : Move K P) : Prop :=
  m ∈ l ∧ ∀ m' ∈ l, keyLe m m'

theorem winner_exists : ∀ (l : List (Move K P)), l ≠ [] → ∃ m, Winner l m
  | [], h => absurd rfl h
  | [m], _ => ⟨m, by simp, fun m' hm' => by
      have : m' = m := List.mem_singleton.mp hm'
      rw [this]; exact Or.inr rfl⟩
  | m :: n :: rest, _ => by
    obtain ⟨w, hw⟩ := winner_exists (n :: rest) (by simp)
    rcases Key.total w.key m.key with h | h | h
    · refine ⟨m, by simp, ?_⟩
      intro m' hm'
      rcases List.mem_cons.mp hm' with e | e
      · rw [e]; exact Or.inr rfl
      · rcases hw.2 m' e with h' | h'
        · exact Or.inl (Key.trans h' h)
        · exact Or.inl (h' ▸ h)
    · refine ⟨m, by simp, ?_⟩
      intro m' hm'
      rcases List.mem_cons.mp hm' with e | e
      · rw [e]; exact Or.inr rfl
      · rcases hw.2 m' e with h' | h'
        · exact Or.inl (h ▸ h')
        · exact Or.inr (h' ▸ h)
    · refine ⟨w, List.mem_cons_of_mem m hw.1, ?_⟩
      intro m' hm'
      rcases List.mem_cons.mp hm' with e | e
      · rw [e]; exact Or.inl h
      · exact hw.2 m' e

theorem winner_key_unique {l : List (Move K P)} {m m' : Move K P}
    (h : Winner l m) (h' : Winner l m') : m.key = m'.key := by
  rcases h.2 m' h'.1 with a | a <;> rcases h'.2 m h.1 with b | b
  · exact absurd (Key.trans a b) (Key.irrefl _)
  · exact b
  · exact a.symm
  · exact a.symm

theorem winner_perm {l l' : List (Move K P)} (hmem : ∀ m, m ∈ l ↔ m ∈ l')
    {m : Move K P} (h : Winner l m) : Winner l' m :=
  ⟨(hmem m).1 h.1, fun m' hm' => h.2 m' ((hmem m').2 hm')⟩

def Placed (base : P) (moves : List (Move K P)) (p : P) : Prop :=
  (moves = [] ∧ p = base) ∨ (∃ m, Winner moves m ∧ p = m.dest)

theorem placed_exists (base : P) (moves : List (Move K P)) : ∃ p, Placed base moves p := by
  by_cases h : moves = []
  · exact ⟨base, Or.inl ⟨h, rfl⟩⟩
  · obtain ⟨m, hm⟩ := winner_exists moves h
    exact ⟨m.dest, Or.inr ⟨m, hm, rfl⟩⟩

theorem placed_unique (base : P) (moves : List (Move K P))
    (hkey : ∀ m ∈ moves, ∀ m' ∈ moves, m.key = m'.key → m.dest = m'.dest)
    {p q : P} (hp : Placed base moves p) (hq : Placed base moves q) : p = q := by
  rcases hp with ⟨he, hp⟩ | ⟨m, hm, hp⟩ <;> rcases hq with ⟨he', hq⟩ | ⟨m', hm', hq⟩
  · rw [hp, hq]
  · rw [he] at hm'; exact absurd hm'.1 (by simp)
  · rw [he'] at hm; exact absurd hm.1 (by simp)
  · rw [hp, hq]; exact hkey m hm.1 m' hm'.1 (winner_key_unique hm hm')

end V1.Moves

* Holes and redaction
:PROPERTIES:
:header-args:lean: :tangle V1/Holes.lean

A log may lack an event (a hole) or a body (redaction, lazy fetch). An event
whose dependency is a hole is in no ideal. The structure of a world never
reads the body store, so removing a body changes the rendering at that atom
alone — every id, closure and frontier stays byte-identical (3.6).

  intro bodies' a ha hne
  constructor
  · exact List.mem_map.mpr ⟨a, ha, rfl⟩
  · refine List.mem_map.mpr ⟨a, ha, ?_⟩
    simp [bodies', hne]

    (render st b).map Prod.fst = (render st b').map Prod.fst := by

* Projection
:PROPERTIES:
:header-args:lean: :tangle V1/Projection.lean
:END:

A projection (the git mirror) folds a path of worlds into a chain of
commits, threading a parent id through a hash rule. Extending the path
extends the output and its ids as a prefix: append-only is a property of
the fold, not of git (3.9).

#+begin_src lean
namespace V1.Projection
variable {W C Id : Type}

structure Rule (W C Id : Type) where
  content : W → W → C
  hash    : Id → C → Id
  root    : Id

def run (R : Rule W C Id) : W → Id → List W → List (Id × C)
  | _, _, [] => []
  | prev, pid, w :: ws =>
    let c := R.content prev w
    let id := R.hash pid c
    (id, c) :: run R w id ws

def project (R : Rule W C Id) (start : W) (π : List W) : List (Id × C) :=
  run R start R.root π

theorem run_append (R : Rule W C Id) :
    ∀ (π ρ : List W) (prev : W) (pid : Id),
      ∃ (w' : W) (id' : Id), run R prev pid (π ++ ρ) = run R prev pid π ++ run R w' id' ρ
  | [], ρ, prev, pid => ⟨prev, pid, by simp [run]⟩
  | w :: ws, ρ, prev, pid => by
    obtain ⟨w', id', h⟩ := run_append R ws ρ w (R.hash pid (R.content prev w))
    exact ⟨w', id', by simp only [List.cons_append, run]; rw [h]⟩

theorem project_append (R : Rule W C Id) (start : W) (π ρ : List W) :
    ∃ tail, project R start (π ++ ρ) = project R start π ++ tail := by
  obtain ⟨_, _, h⟩ := run_append R π ρ start R.root
  exact ⟨_, h⟩

theorem ids_prefix (R : Rule W C Id) (start : W) (π ρ : List W) :
    ∃ tail, (project R start (π ++ ρ)).map Prod.fst = (project R start π).map Prod.fst ++ tail := by
  obtain ⟨tail, h⟩ := project_append R start π ρ
  exact ⟨tail.map Prod.fst, by rw [h, List.map_append]⟩

* Conflicts
:PROPERTIES:
:header-args:lean: :tangle V1/Conflicts.lean
:END:

A conflict is derived: two incomparable events that overwrite the same
target. A resolution lies above every side and declares the conflict, so it
sits in the up-set of each side and =drop= of any side removes it (5.5).
Agreement is equality under =M= on the two worlds with one side removed —
in the homotopical reading, a 2-cell, computed rather than stored (5.6).
Two incomparable resolutions of one conflict are in conflict on the
conflict's id: nesting needs no special case (5.7). All of this is stated
over =DocType=.

#+begin_src lean
import V1.Worlds
import V1.DocType

namespace V1.Conflicts
open V1.Worlds
variable {α : Type} [PartialOrder α] (D : V1.DocType α)

def Conf (e f : α) : Prop :=
  ¬ e ≤ f ∧ ¬ f ≤ e ∧ ∃ t, D.ow e t ∧ D.ow f t

structure Conflict (α : Type) (T : Type) where
  target : T
  sides  : Pred α

def IsResolution (κ : Conflict α D.T) (cid : D.T) (r : α) : Prop :=
  (∀ s, κ.sides s → s ≤ r) ∧ D.ow r cid

def Open (κ : Conflict α D.T) (cid : D.T) (S : Pred α) : Prop :=
  (∀ s, κ.sides s → S s) ∧ ¬ ∃ r, S r ∧ IsResolution D κ cid r

/-- 5.5 -/
theorem drop_side_drops_resolution (κ : Conflict α D.T) (cid : D.T)
    {S : Pred α} {s r : α} (hs : κ.sides s) (hr : IsResolution D κ cid r) :
    ¬ drop S (fun x => x = s) r := by
  intro ⟨_, hnot⟩
  exact hnot ⟨s, rfl, hr.1 s hs⟩

theorem resolution_upper (κ : Conflict α D.T) (cid : D.T) {r : α}
    (hr : IsResolution D κ cid r) : ∀ s, κ.sides s → s ≤ r := hr.1

/-- 5.6 -/
def Agree (S : Pred α) (e f : α) : Prop :=
  D.M (drop S (fun x => x = f)) = D.M (drop S (fun x => x = e))

theorem agree_symm (S : Pred α) (e f : α) : Agree D S e f → Agree D S f e := fun h => h.symm
theorem agree_refl (S : Pred α) (e : α) : Agree D S e e := rfl

/-- 5.7 -/
theorem nested (κ : Conflict α D.T) (cid : D.T) {r₁ r₂ : α}
    (h₁ : IsResolution D κ cid r₁) (h₂ : IsResolution D κ cid r₂)
    (hinc : ¬ r₁ ≤ r₂ ∧ ¬ r₂ ≤ r₁) : Conf D r₁ r₂ :=
  ⟨hinc.1, hinc.2, cid, h₁.2, h₂.2⟩

end V1.Conflicts

* Authority
:PROPERTIES:
:header-args:lean: :tangle V1/Authority.lean
:END:

Identity is a key. A certificate delegates from a parent certificate, so
the chain =root ⊑ … ⊑ c ⊑ e= lies in $\downarrow e$ (the first draft had
this backwards; the proof caught it). Validity of an event therefore depends
only on the events below it and on revocations that target links of its
chain: two logs that agree there agree on validity (6.4). No peer needs the
whole log to judge an event.

#+begin_src lean
namespace V1.Authority
variable {Ev : Type}

structure Judge (Ev : Type) where
  le        : Ev → Ev → Prop
  wellFormed: Ev → Ev → Prop
  inScope   : Ev → Ev → Prop
  isRoot    : Ev → Prop

def ChainOk (J : Judge Ev) (L : Ev → Prop) : List Ev → Prop
  | [] => False
  | [r] => L r ∧ J.isRoot r
  | c :: p :: rest => L c ∧ J.wellFormed c p ∧ J.le p c ∧ ChainOk J L (p :: rest)

def ValidVia (J : Judge Ev) (L : Ev → Prop) (e : Ev) (ch : List Ev) : Prop :=
  match ch with
  | [] => False
  | c :: _ => J.le c e ∧ J.inScope e c ∧ ChainOk J L ch

def Valid (J : Judge Ev) (L : Ev → Prop) (e : Ev) : Prop := ∃ ch, ValidVia J L e ch

theorem chain_below (J : Judge Ev) (htrans : ∀ {a b c}, J.le a b → J.le b c → J.le a c)
    (hrefl : ∀ a, J.le a a) (L : Ev → Prop) :
    ∀ (ch : List Ev) (c : Ev), ChainOk J L (c :: ch) →
      ∀ x, x ∈ c :: ch → J.le x c := by
  intro ch
  induction ch with
  | nil =>
    intro c _ x hx
    have h : x = c := List.mem_singleton.mp hx
    rw [h]; exact hrefl c
  | cons p rest ih =>
    intro c hok x hx
    obtain ⟨_, _, hpc, hrest⟩ := hok
    cases List.mem_cons.mp hx with
    | inl h => rw [h]; exact hrefl c
    | inr h => exact htrans (ih p hrest x h) hpc

theorem chainOk_transport (J : Judge Ev) (L L' : Ev → Prop) (e : Ev)
    (hagree : ∀ x, J.le x e → (L x ↔ L' x)) :
    ∀ (l : List Ev), (∀ x, x ∈ l → J.le x e) → ChainOk J L l → ChainOk J L' l := by
  intro l
  induction l with
  | nil => intro _ h; exact h
  | cons a t ih =>
    intro hb hok
    match t, hok with
    | [], ⟨hLa, hr⟩ => exact ⟨(hagree a (hb a (by simp))).1 hLa, hr⟩
    | p :: r, ⟨hLa, hwf, hle, hrest⟩ =>
      exact ⟨(hagree a (hb a (by simp))).1 hLa, hwf, hle,
             ih (fun x hx => hb x (List.mem_cons_of_mem a hx)) hrest⟩

/-- 6.4 without revocations -/
theorem valid_local (J : Judge Ev) (htrans : ∀ {a b c}, J.le a b → J.le b c → J.le a c)
    (hrefl : ∀ a, J.le a a) (L L' : Ev → Prop) (e : Ev)
    (hagree : ∀ x, J.le x e → (L x ↔ L' x)) :
    Valid J L e → Valid J L' e := by
  intro ⟨ch, hv⟩
  refine ⟨ch, ?_⟩
  match ch, hv with
  | c :: rest, ⟨hce, hsc, hok⟩ =>
    refine ⟨hce, hsc, ?_⟩
    have below : ∀ x, x ∈ c :: rest → J.le x e :=
      fun x hx => htrans (chain_below J htrans hrefl L rest c hok x hx) hce
    exact chainOk_transport J L L' e hagree (c :: rest) below hok

structure Revoke (Ev : Type) where
  rev    : Ev → Ev → Prop
  before : Ev → Ev → Prop

def LinkRevoked (Rv : Revoke Ev) (L : Ev → Prop) (e c : Ev) : Prop :=
  ∃ v, L v ∧ Rv.rev v c ∧ Rv.before v e

def ValidViaR (J : Judge Ev) (Rv : Revoke Ev) (L : Ev → Prop) (e : Ev) (ch : List Ev) : Prop :=
  ValidVia J L e ch ∧ ∀ c, c ∈ ch → ¬ LinkRevoked Rv L e c

def ValidR (J : Judge Ev) (Rv : Revoke Ev) (L : Ev → Prop) (e : Ev) : Prop :=
  ∃ ch, ValidViaR J Rv L e ch

/-- 6.4 with revocations -/
theorem validR_local (J : Judge Ev) (Rv : Revoke Ev)
    (htrans : ∀ {a b c}, J.le a b → J.le b c → J.le a c) (hrefl : ∀ a, J.le a a)
    (L L' : Ev → Prop) (e : Ev)
    (hagree : ∀ x, J.le x e → (L x ↔ L' x))
    (hrev : ∀ v c, J.le c e → Rv.rev v c → Rv.before v e → (L v ↔ L' v)) :
    ValidR J Rv L e → ValidR J Rv L' e := by
  intro ⟨ch, hv, hnr⟩
  refine ⟨ch, ?_, ?_⟩
  · match ch, hv with
    | c :: rest, ⟨hce, hsc, hok⟩ =>
      refine ⟨hce, hsc, ?_⟩
      have below : ∀ x, x ∈ c :: rest → J.le x e :=
        fun x hx => htrans (chain_below J htrans hrefl L rest c hok x hx) hce
      exact chainOk_transport J L L' e hagree (c :: rest) below hok
  · intro c hc ⟨v, hLv, hrv, hbv⟩
    match ch, hv with
    | c0 :: rest, ⟨hce, _, hok⟩ =>
      have hcle : J.le c e := htrans (chain_below J htrans hrefl L rest c0 hok c hc) hce
      exact hnr c hc ⟨v, (hrev v c hcle hrv hbv).2 hLv, hrv, hbv⟩

end V1.Authority

* Tasks
:PROPERTIES:
:header-args:lean: :tangle V1/Tasks.lean
:END:

The task graph is a second poset — tasks under =blockedBy= — and its
done-sets are ideals. So the whole of [[*Worlds]] applies without a new
definition, and =ready= is literally the cover antichain: a task is ready
in $D$ exactly when adopting it and dropping it again returns to $D$
(2.7(a) with a singleton). That is the instance the vision's "one signature"
claim requires, exhibited rather than asserted. Width and lanes are
[[*Dilworth]].

#+begin_src lean

  constructor
  · intro ⟨hnd, hmin⟩

    · intro x ⟨hx, hdx⟩; subst hx; exact hnd hdx
    · intro x ⟨c, hc, hxc⟩ hne; subst hc; exact hmin x hxc hne

    refine ⟨fun hd => hdisj t ⟨rfl, hd⟩, ?_⟩

    exact hbelow r ⟨t, rfl, hrt⟩ hne

* Contraction
:PROPERTIES:
:header-args:lean: :tangle V1/Contraction.lean
:END:

Zooming out contracts a box of tasks to its representative. With the box
done as a whole or not at all, the image of an ideal is a down-set of the
quotient relation, and a task outside the box that is minimal in the
complement stays minimal (7.6). Alloy's bounded search sharpened this:
the boundary condition (no =blockedBy= edge across the box wall) is needed
only for the readiness of the box itself; outside it, box atomicity
suffices. That sharper form is [[*Alloy — bounded search where a counterexample is the point][Alloy]]'s and is not yet proved here.

#+begin_src lean
import V1.Worlds

namespace V1.Contraction
open V1.Worlds
variable {α : Type} [PartialOrder α]
variable (box : α → Prop) (b : α) [DecidablePred box]

def q (x : α) : α := if box x then b else x
def qle (u v : α) : Prop := ∃ x y, q box b x = u ∧ q box b y = v ∧ x ≤ y
def image (D : Pred α) : Pred α := fun u => ∃ x, D x ∧ q box b x = u
def IsDown (R : α → α → Prop) (S : Pred α) : Prop := ∀ u v, S u → R v u → S v
def BoxAtomic (D : Pred α) : Prop := (∀ x, box x → D x) ∨ (∀ x, box x → ¬ D x)

theorem q_eq_self {x : α} (h : ¬ box x) : q box b x = x := by simp [q, h]
theorem q_eq_b {x : α} (h : box x) : q box b x = b := by simp [q, h]

theorem image_down (hb : box b) (D : Pred α) (hD : IsIdeal D) (hat : BoxAtomic box D) :
    IsDown (qle box b) (image box b D) := by
  intro u v ⟨x, hxD, hqx⟩ ⟨y', x', hqy', hqx', hle⟩
  refine ⟨y', ?_, hqy'⟩
  by_cases hbx' : box x'
  · have hu : u = b := by rw [← hqx']; exact q_eq_b box b hbx'
    have hbx : box x := by
      apply Classical.byContradiction; intro hn
      have : u = x := by rw [← hqx]; exact q_eq_self box b hn
      exact hn (by rw [← this, hu]; exact hb)
    rcases hat with hall | hnone
    · exact hD x' y' (hall x' hbx') hle
    · exact absurd hxD (hnone x hbx)
  · have : x' = u := by rw [← hqx']; exact (q_eq_self box b hbx').symm
    subst this
    by_cases hbx : box x
    · have : x' = b := by rw [← hqx]; exact q_eq_b box b hbx
      exact absurd (this ▸ hb) hbx'
    · have : x = x' := by rw [← hqx]; exact (q_eq_self box b hbx).symm
      rw [this] at hxD
      exact hD x' y' hxD hle

theorem min_preserved (hb : box b) (D : Pred α) (hat : BoxAtomic box D)
    {x : α} (hbx : ¬ box x) (hxD : ¬ D x)
    (hmin : ∀ y, y ≤ x → ¬ D y → y = x) :
    ∀ v, image box b (fun z => ¬ D z) v → qle box b v (q box b x) → v = q box b x := by
  intro v ⟨z, hzD, hqz⟩ ⟨y', x', hqy', hqx', hle⟩
  rw [q_eq_self box b hbx] at hqx' ⊢
  have hx' : x' = x := by
    by_cases h : box x'
    · have : b = x := by rw [← hqx']; exact (q_eq_b box b h).symm
      exact absurd (this ▸ hb) hbx
    · rw [← hqx']; exact (q_eq_self box b h).symm
  subst hx'
  by_cases hby : box y'
  · have hv : v = b := by rw [← hqy']; exact q_eq_b box b hby
    have hbz : box z := by
      apply Classical.byContradiction; intro hn
      have : v = z := by rw [← hqz]; exact q_eq_self box b hn
      exact hn (by rw [← this, hv]; exact hb)
    rcases hat with hall | hnone
    · exact absurd (hall z hbz) hzD
    · have := hmin y' hle (hnone y' hby)
      exact absurd (this ▸ hby) hbx
  · have hv : v = y' := by rw [← hqy']; exact q_eq_self box b hby
    subst hv
    have hzv : z = v := by
      by_cases h : box z
      · have : v = b := by rw [← hqz]; exact q_eq_b box b h
        exact absurd (this ▸ hb) hby
      · rw [← hqz]; exact (q_eq_self box b h).symm
    subst hzv
    exact hmin z hle hzD

* Dilworth
:PROPERTIES:
:header-args:lean: :tangle V1/Dilworth.lean
:END:

Dilworth's theorem: the minimum number of chains covering a finite poset
equals its width. For the task graph this is the number of parallel lanes
the remaining work can be cut into, computable from =blockedBy= alone
(7.4). The proof is Perles' (1963), by strong induction on the poset,
indexed so that the chains are labelled by the elements of a maximum
antichain — which is what makes the two halves of the induction glue
without bijection bookkeeping. Cover form first, then the decomposition
into pairwise disjoint chains. Not in Mathlib; ~400 lines here.

#+begin_src lean
import Mathlib.Data.Finset.Card
import Mathlib.Data.Finset.Max
import Mathlib.Order.Preorder.Finite
import Mathlib.Data.Fintype.Card
import Mathlib.Data.Finset.Powerset
import Mathlib.Data.Finset.Max

open Classical

namespace V1.Dilworth
variable {α : Type*} [PartialOrder α]

def IsChainF (C : Finset α) : Prop := ∀ a ∈ C, ∀ b ∈ C, a ≤ b ∨ b ≤ a
def IsAntichainF (A : Finset α) : Prop := ∀ a ∈ A, ∀ b ∈ A, a ≤ b → a = b
def MaxAntichain (P A : Finset α) : Prop :=
  A ⊆ P ∧ IsAntichainF A ∧ ∀ B ⊆ P, IsAntichainF B → B.card ≤ A.card
/-- a chain cover of `P` indexed by `A`, every chain containing its index -/
def CoverBy (P A : Finset α) (c : α → Finset α) : Prop :=
  (∀ a ∈ A, IsChainF (c a) ∧ c a ⊆ P ∧ a ∈ c a) ∧ (∀ x ∈ P, ∃ a ∈ A, x ∈ c a)
noncomputable def minSet (P : Finset α) : Finset α := P.filter (fun x => ∀ z ∈ P, z ≤ x → z = x)
noncomputable def maxSet (P : Finset α) : Finset α := P.filter (fun x => ∀ z ∈ P, x ≤ z → z = x)

/-! ### small lemmas -/

theorem chain_meets_antichain {C A : Finset α} (hC : IsChainF C) (hA : IsAntichainF A)
    {a b : α} (ha : a ∈ A) (hb : b ∈ A) (haC : a ∈ C) (hbC : b ∈ C) : a = b := by
  rcases hC a haC b hbC with h | h
  · exact hA a ha b hb h
  · exact (hA b hb a ha h).symm

theorem exists_min_below (P : Finset α) {b : α} (hb : b ∈ P) :
    ∃ z ∈ minSet P, z ≤ b := by
  have hne : (P.filter (fun x => x ≤ b)).Nonempty := ⟨b, by simp [hb]⟩
  obtain ⟨z, hz⟩ := Finset.exists_minimal hne
  have hzP : z ∈ P := (Finset.mem_filter.1 hz.1).1
  have hzb : z ≤ b := (Finset.mem_filter.1 hz.1).2
  refine ⟨z, ?_, hzb⟩
  rw [minSet, Finset.mem_filter]
  refine ⟨hzP, ?_⟩
  intro w hw hwz
  have hw' : w ∈ P.filter (fun x => x ≤ b) := by
    rw [Finset.mem_filter]; exact ⟨hw, le_trans hwz hzb⟩
  exact le_antisymm hwz (hz.2 hw' hwz)

theorem exists_max_above (P : Finset α) {b : α} (hb : b ∈ P) :
    ∃ z ∈ maxSet P, b ≤ z := by
  have hne : (P.filter (fun x => b ≤ x)).Nonempty := ⟨b, by simp [hb]⟩
  obtain ⟨z, hz⟩ := Finset.exists_maximal hne
  have hzP : z ∈ P := (Finset.mem_filter.1 hz.1).1
  have hbz : b ≤ z := (Finset.mem_filter.1 hz.1).2
  refine ⟨z, ?_, hbz⟩
  rw [maxSet, Finset.mem_filter]
  refine ⟨hzP, ?_⟩
  intro w hw hzw
  have hw' : w ∈ P.filter (fun x => b ≤ x) := by
    rw [Finset.mem_filter]; exact ⟨hw, le_trans hbz hzw⟩
  exact le_antisymm (hz.2 hw' hzw) hzw

theorem minSet_subset_antichain_eq {P A : Finset α} (hAP : A ⊆ P) (hA : IsAntichainF A)
    (h : minSet P ⊆ A) : A = minSet P := by
  apply Finset.Subset.antisymm _ h
  intro a ha
  obtain ⟨z, hz, hza⟩ := exists_min_below P (hAP ha)
  have : z = a := hA z (h hz) a ha hza
  rw [← this]; exact hz

theorem maxSet_subset_antichain_eq {P A : Finset α} (hAP : A ⊆ P) (hA : IsAntichainF A)
    (h : maxSet P ⊆ A) : A = maxSet P := by
  apply Finset.Subset.antisymm _ h
  intro a ha
  obtain ⟨z, hz, haz⟩ := exists_max_above P (hAP ha)
  have : a = z := hA a ha z (h hz) haz
  rw [this]; exact hz

/-- re-index a cover from one maximum antichain to another of the same size -/
theorem reindex {P A B : Finset α} {c : α → Finset α} (hcov : CoverBy P B c)
    (hAP : A ⊆ P) (hA : IsAntichainF A) (hcard : B.card ≤ A.card) :
    ∃ c', CoverBy P A c' := by
  -- for each a ∈ A pick the chain that contains it
  have hpick : ∀ a ∈ A, ∃ b ∈ B, a ∈ c b := fun a ha => hcov.2 a (hAP ha)
  let g : (a : α) → a ∈ A → α := fun a ha => Classical.choose (hpick a ha)
  have hg : ∀ a (ha : a ∈ A), g a ha ∈ B ∧ a ∈ c (g a ha) :=
    fun a ha => Classical.choose_spec (hpick a ha)
  have ginj : ∀ a₁ a₂ (h₁ : a₁ ∈ A) (h₂ : a₂ ∈ A), g a₁ h₁ = g a₂ h₂ → a₁ = a₂ := by
    intro a₁ a₂ h₁ h₂ heq
    have hb := (hg a₁ h₁).1
    have hC := (hcov.1 _ hb).1
    have h2 : a₂ ∈ c (g a₁ h₁) := by rw [heq]; exact (hg a₂ h₂).2
    exact chain_meets_antichain hC hA h₁ h₂ (hg a₁ h₁).2 h2
  have gsurj := Finset.surj_on_of_inj_on_of_card_le g (fun a ha => (hg a ha).1) ginj hcard
  refine ⟨fun a => if h : a ∈ A then c (g a h) else ∅, ?_, ?_⟩
  · intro a ha
    simp only [dif_pos ha]
    exact ⟨(hcov.1 _ (hg a ha).1).1, (hcov.1 _ (hg a ha).1).2.1, (hg a ha).2⟩
  · intro x hx
    obtain ⟨b, hb, hxb⟩ := hcov.2 x hx
    obtain ⟨a, ha, hab⟩ := gsurj b hb
    refine ⟨a, ha, ?_⟩
    simp only [dif_pos ha]
    rw [← hab]; exact hxb

/-! ### the theorem -/

theorem dilworth (P : Finset α) : ∀ A, MaxAntichain P A → ∃ c, CoverBy P A c := by
  induction P using Finset.strongInduction with
  | H P ih =>
  intro A hA
  obtain ⟨hAP, hAac, hAmax⟩ := hA
  by_cases hPe : P = ∅
  · refine ⟨fun _ => ∅, ?_, ?_⟩
    · intro a ha; exact absurd (hAP ha) (by rw [hPe]; simp)
    · intro x hx; exact absurd hx (by rw [hPe]; simp)
  -- P nonempty
  by_cases hB : ∃ B, MaxAntichain P B ∧ B ≠ minSet P ∧ B ≠ maxSet P
  · -- Case 1
    obtain ⟨B, ⟨hBP, hBac, hBmax⟩, hBmin, hBmaxs⟩ := hB
    let Pp := P.filter (fun x => ∃ b ∈ B, b ≤ x)
    let Pm := P.filter (fun x => ∃ b ∈ B, x ≤ b)
    have hPpP : Pp ⊆ P := Finset.filter_subset _ _
    have hPmP : Pm ⊆ P := Finset.filter_subset _ _
    have hBPp : B ⊆ Pp := fun b hb => Finset.mem_filter.2 ⟨hBP hb, b, hb, le_rfl⟩
    have hBPm : B ⊆ Pm := fun b hb => Finset.mem_filter.2 ⟨hBP hb, b, hb, le_rfl⟩
    -- a minimal element outside B is not in Pp
    have hPp_ssub : Pp ⊂ P := by
      rw [Finset.ssubset_iff_subset_ne]
      refine ⟨hPpP, ?_⟩
      intro heq
      apply hBmin
      apply minSet_subset_antichain_eq hBP hBac
      intro z hz
      have hzP : z ∈ P := (Finset.mem_filter.1 hz).1
      have hzPp : z ∈ Pp := by rw [heq]; exact hzP
      obtain ⟨b, hb, hbz⟩ := (Finset.mem_filter.1 hzPp).2
      have : b = z := (Finset.mem_filter.1 hz).2 b (hBP hb) hbz
      rw [← this]; exact hb
    have hPm_ssub : Pm ⊂ P := by
      rw [Finset.ssubset_iff_subset_ne]
      refine ⟨hPmP, ?_⟩
      intro heq
      apply hBmaxs
      apply maxSet_subset_antichain_eq hBP hBac
      intro z hz
      have hzP : z ∈ P := (Finset.mem_filter.1 hz).1
      have hzPm : z ∈ Pm := by rw [heq]; exact hzP
      obtain ⟨b, hb, hzb⟩ := (Finset.mem_filter.1 hzPm).2
      have : b = z := (Finset.mem_filter.1 hz).2 b (hBP hb) hzb
      rw [← this]; exact hb
    have hBmaxPp : MaxAntichain Pp B :=
      ⟨hBPp, hBac, fun C hC hCac => hBmax C (hC.trans hPpP) hCac⟩
    have hBmaxPm : MaxAntichain Pm B :=
      ⟨hBPm, hBac, fun C hC hCac => hBmax C (hC.trans hPmP) hCac⟩
    obtain ⟨cp, hcp⟩ := ih Pp hPp_ssub B hBmaxPp
    obtain ⟨cm, hcm⟩ := ih Pm hPm_ssub B hBmaxPm
    -- chains of the upper cover sit above their index, lower ones below
    have above : ∀ b ∈ B, ∀ x ∈ cp b, b ≤ x := by
      intro b hb x hx
      have hxPp : x ∈ Pp := (hcp.1 b hb).2.1 hx
      obtain ⟨b', hb', hb'x⟩ := (Finset.mem_filter.1 hxPp).2
      rcases (hcp.1 b hb).1 b (hcp.1 b hb).2.2 x hx with h | h
      · exact h
      · have : b' = b := hBac b' hb' b hb (le_trans hb'x h)
        rw [← this]; exact hb'x
    have below : ∀ b ∈ B, ∀ x ∈ cm b, x ≤ b := by
      intro b hb x hx
      have hxPm : x ∈ Pm := (hcm.1 b hb).2.1 hx
      obtain ⟨b', hb', hxb'⟩ := (Finset.mem_filter.1 hxPm).2
      rcases (hcm.1 b hb).1 b (hcm.1 b hb).2.2 x hx with h | h
      · have : b = b' := hBac b hb b' hb' (le_trans h hxb')
        rw [this]; exact hxb'
      · exact h
    have hcovB : CoverBy P B (fun b => cp b ∪ cm b) := by
      refine ⟨?_, ?_⟩
      · intro b hb
        refine ⟨?_, ?_, ?_⟩
        · intro u hu v hv
          rcases Finset.mem_union.1 hu with hu | hu <;> rcases Finset.mem_union.1 hv with hv | hv
          · exact (hcp.1 b hb).1 u hu v hv
          · exact Or.inr (le_trans (below b hb v hv) (above b hb u hu))
          · exact Or.inl (le_trans (below b hb u hu) (above b hb v hv))
          · exact (hcm.1 b hb).1 u hu v hv
        · intro u hu
          rcases Finset.mem_union.1 hu with hu | hu
          · exact hPpP ((hcp.1 b hb).2.1 hu)
          · exact hPmP ((hcm.1 b hb).2.1 hu)
        · exact Finset.mem_union.2 (Or.inl (hcp.1 b hb).2.2)
      · intro x hx
        -- x is comparable with some b ∈ B, else B ∪ {x} is a bigger antichain
        have hcomp : ∃ b ∈ B, b ≤ x ∨ x ≤ b := by
          by_contra hno
          push_neg at hno
          have hxB : x ∉ B := fun h => (hno x h).1 le_rfl
          have hac : IsAntichainF (insert x B) := by
            intro u hu v hv huv
            rcases Finset.mem_insert.1 hu with hu | hu <;> rcases Finset.mem_insert.1 hv with hv | hv
            · rw [hu, hv]
            · exact absurd huv (by rw [hu]; exact (hno v hv).2)
            · exact absurd huv (by rw [hv]; exact (hno u hu).1)
            · exact hBac u hu v hv huv
          have hsub : insert x B ⊆ P := Finset.insert_subset hx hBP
          have := hBmax _ hsub hac
          rw [Finset.card_insert_of_notMem hxB] at this
          omega
        obtain ⟨b, hb, h | h⟩ := hcomp
        · obtain ⟨b', hb', hxb'⟩ := hcp.2 x (Finset.mem_filter.2 ⟨hx, b, hb, h⟩)
          exact ⟨b', hb', Finset.mem_union.2 (Or.inl hxb')⟩
        · obtain ⟨b', hb', hxb'⟩ := hcm.2 x (Finset.mem_filter.2 ⟨hx, b, hb, h⟩)
          exact ⟨b', hb', Finset.mem_union.2 (Or.inr hxb')⟩
    exact reindex hcovB hAP hAac (hAmax B hBP hBac)
  · -- Case 2: every maximum antichain is minSet P or maxSet P
    push_neg at hB
    have hAmm : A = minSet P ∨ A = maxSet P := by
      by_contra h
      push_neg at h
      exact h.2 (hB A ⟨hAP, hAac, hAmax⟩ h.1)
    -- a comparable pair x ≤ y, x minimal, y maximal, with one of them in A
    have hpair : ∃ x y, x ∈ minSet P ∧ y ∈ maxSet P ∧ x ≤ y ∧ (x ∈ A ∨ y ∈ A) := by
      obtain ⟨p, hp⟩ := Finset.nonempty_iff_ne_empty.2 hPe
      rcases hAmm with h | h
      · obtain ⟨x, hx, _⟩ := exists_min_below P hp
        obtain ⟨y, hy, hxy⟩ := exists_max_above P ((Finset.mem_filter.1 hx).1)
        exact ⟨x, y, hx, hy, hxy, Or.inl (by rw [h]; exact hx)⟩
      · obtain ⟨y, hy, _⟩ := exists_max_above P hp
        obtain ⟨x, hx, hxy⟩ := exists_min_below P ((Finset.mem_filter.1 hy).1)
        exact ⟨x, y, hx, hy, hxy, Or.inr (by rw [h]; exact hy)⟩
    obtain ⟨x, y, hxmin, hymax, hxy, hxyA⟩ := hpair
    have hxP : x ∈ P := (Finset.mem_filter.1 hxmin).1
    have hyP : y ∈ P := (Finset.mem_filter.1 hymax).1
    -- the index in A that the pair removes
    let a0 := if x ∈ A then x else y
    have ha0A : a0 ∈ A := by
      simp only [a0]; split_ifs with h
      · exact h
      · rcases hxyA with h' | h'; exact absurd h' h; exact h'
    have ha0xy : a0 = x ∨ a0 = y := by
      simp only [a0]; split_ifs
      · exact Or.inl rfl
      · exact Or.inr rfl
    -- A contains at most one of x, y: if both, then x = y
    have hboth : x ∈ A → y ∈ A → x = y := fun hx hy => hAac x hx y hy hxy
    let P' := P \ {x, y}
    let A' := A.erase a0
    have hP'P : P' ⊆ P := Finset.sdiff_subset
    have hP'_ssub : P' ⊂ P := by
      rw [Finset.ssubset_iff_subset_ne]
      refine ⟨hP'P, ?_⟩
      intro heq
      have : x ∈ P' := by rw [heq]; exact hxP
      exact (Finset.mem_sdiff.1 this).2 (by simp)
    have hA'P' : A' ⊆ P' := by
      intro a ha
      obtain ⟨hne, haA⟩ := Finset.mem_erase.1 ha
      rw [Finset.mem_sdiff]
      refine ⟨hAP haA, ?_⟩
      intro hmem
      rcases Finset.mem_insert.1 hmem with h | h
      · -- a = x
        subst h
        rcases ha0xy with h0 | h0
        · exact hne h0.symm
        · -- a0 = y ∈ A and x ∈ A ⇒ x = y ⇒ a0 = x
          have hyA : y ∈ A := h0 ▸ ha0A
          exact hne (by rw [h0]; exact hboth haA hyA)
      · have h : a = y := Finset.mem_singleton.1 h
        subst h
        rcases ha0xy with h0 | h0
        · have hxA : x ∈ A := h0 ▸ ha0A
          exact hne (by rw [h0]; exact (hboth hxA haA).symm)
        · exact hne h0.symm
    have hA'max : MaxAntichain P' A' := by
      refine ⟨hA'P', fun u hu v hv => hAac u (Finset.mem_of_mem_erase hu) v (Finset.mem_of_mem_erase hv), ?_⟩
      intro C hC hCac
      by_contra hlt
      push_neg at hlt
      rw [Finset.card_erase_of_mem ha0A] at hlt
      have hCP : C ⊆ P := hC.trans hP'P
      have hCle : C.card ≤ A.card := hAmax C hCP hCac
      have hAne : 0 < A.card := Finset.card_pos.2 ⟨a0, ha0A⟩
      have hCeq : C.card = A.card := by omega
      have hCmax : MaxAntichain P C := ⟨hCP, hCac, fun D hD hDac => hCeq ▸ hAmax D hD hDac⟩
      have hCmm : C = minSet P ∨ C = maxSet P := by
        by_contra h
        push_neg at h
        exact h.2 (hB C hCmax h.1)
      rcases hCmm with h | h
      · have : x ∈ C := by rw [h]; exact hxmin
        exact (Finset.mem_sdiff.1 (hC this)).2 (by simp)
      · have : y ∈ C := by rw [h]; exact hymax
        exact (Finset.mem_sdiff.1 (hC this)).2 (by simp)
    obtain ⟨c', hc'⟩ := ih P' hP'_ssub A' hA'max
    refine ⟨fun a => if a = a0 then {x, y} else c' a, ?_, ?_⟩
    · intro a ha
      by_cases h : a = a0
      · simp only [if_pos h]
        refine ⟨?_, ?_, ?_⟩
        · intro u hu v hv
          rcases Finset.mem_insert.1 hu with hu | hu <;> rcases Finset.mem_insert.1 hv with hv | hv
          · rw [hu, hv]; exact Or.inl le_rfl
          · rw [hu, Finset.mem_singleton.1 hv]; exact Or.inl hxy
          · rw [Finset.mem_singleton.1 hu, hv]; exact Or.inr hxy
          · rw [Finset.mem_singleton.1 hu, Finset.mem_singleton.1 hv]; exact Or.inl le_rfl
        · intro u hu
          rcases Finset.mem_insert.1 hu with hu | hu
          · rw [hu]; exact hxP
          · rw [Finset.mem_singleton.1 hu]; exact hyP
        · rw [h]; rcases ha0xy with h0 | h0 <;> rw [h0] <;> simp
      · simp only [if_neg h]
        have ha' : a ∈ A' := Finset.mem_erase.2 ⟨h, ha⟩
        exact ⟨(hc'.1 a ha').1, (hc'.1 a ha').2.1.trans hP'P, (hc'.1 a ha').2.2⟩
    · intro z hz
      by_cases hzxy : z ∈ ({x, y} : Finset α)
      · refine ⟨a0, ha0A, ?_⟩
        simp only [if_pos rfl]; exact hzxy
      · have hzP' : z ∈ P' := Finset.mem_sdiff.2 ⟨hz, hzxy⟩
        obtain ⟨a, ha, hza⟩ := hc'.2 z hzP'
        refine ⟨a, Finset.mem_of_mem_erase ha, ?_⟩
        simp only [if_neg (Finset.ne_of_mem_erase ha)]; exact hza

/-- Corollary: the easy direction. Any antichain is no larger than any cover. -/
theorem antichain_le_cover {P A B : Finset α} {c : α → Finset α} (hcov : CoverBy P B c)
    (hAP : A ⊆ P) (hA : IsAntichainF A) : A.card ≤ B.card := by
  have hpick : ∀ a ∈ A, ∃ b ∈ B, a ∈ c b := fun a ha => hcov.2 a (hAP ha)
  let g : α → α := fun a => if h : a ∈ A then Classical.choose (hpick a h) else a
  apply Finset.card_le_card_of_injOn g
  · intro a ha
    have ha' : a ∈ A := ha
    simp only [g, dif_pos ha']
    exact (Classical.choose_spec (hpick a ha')).1
  · intro a₁ h₁ a₂ h₂ heq
    have h₁' : a₁ ∈ A := h₁
    have h₂' : a₂ ∈ A := h₂
    simp only [g, dif_pos h₁', dif_pos h₂'] at heq
    have hb := (Classical.choose_spec (hpick a₁ h₁')).1
    have hC := (hcov.1 _ hb).1
    have h2 : a₂ ∈ c (Classical.choose (hpick a₁ h₁')) := by
      rw [heq]; exact (Classical.choose_spec (hpick a₂ h₂')).2
    exact chain_meets_antichain hC hA h₁' h₂' (Classical.choose_spec (hpick a₁ h₁')).2 h2

end V1.Dilworth

/-! ### Dilworth in the classical form: min #chains = width -/
namespace V1.Dilworth
variable {α : Type*} [PartialOrder α]

/-- Every finite poset has a maximum antichain. -/
theorem exists_maxAntichain (P : Finset α) : ∃ A, MaxAntichain P A := by
  classical
  let S := P.powerset.filter IsAntichainF
  have hS : S.Nonempty := ⟨∅, by simp [S, IsAntichainF]⟩
  obtain ⟨A, hA, hmax⟩ := Finset.exists_max_image S Finset.card hS
  have hA' := Finset.mem_filter.1 hA
  refine ⟨A, Finset.mem_powerset.1 hA'.1, hA'.2, ?_⟩
  intro B hB hBac
  exact hmax B (Finset.mem_filter.2 ⟨Finset.mem_powerset.2 hB, hBac⟩)

/-- width = size of a maximum antichain; the theorem gives a cover of exactly that
    many chains, and no cover can be smaller. -/
theorem width_eq_min_cover (P : Finset α) :
    ∃ A c, MaxAntichain P A ∧ CoverBy P A c ∧
      ∀ B (c' : α → Finset α), CoverBy P B c' → A.card ≤ B.card := by
  obtain ⟨A, hA⟩ := exists_maxAntichain P
  obtain ⟨c, hc⟩ := dilworth P A hA
  exact ⟨A, c, hA, hc, fun B c' hc' => antichain_le_cover hc' hA.1 hA.2.1⟩

end V1.Dilworth

/-! ### Decomposition form: the chains can be made pairwise disjoint -/
namespace V1.Dilworth
variable {α : Type*} [PartialOrder α]

theorem disjoint_cover {P B : Finset α} {c : α → Finset α} (hcov : CoverBy P B c) :
    ∃ d : α → Finset α,
      (∀ b ∈ B, IsChainF (d b) ∧ d b ⊆ P) ∧ (∀ x ∈ P, ∃ b ∈ B, x ∈ d b) ∧
      (∀ b₁ ∈ B, ∀ b₂ ∈ B, b₁ ≠ b₂ → Disjoint (d b₁) (d b₂)) := by
  classical
  -- send every element to one chain that contains it
  let pick : α → α := fun x => if h : x ∈ P then Classical.choose (hcov.2 x h) else x
  have hpick : ∀ x (h : x ∈ P), pick x ∈ B ∧ x ∈ c (pick x) := by
    intro x h
    simp only [pick, dif_pos h]
    exact Classical.choose_spec (hcov.2 x h)
  refine ⟨fun b => (c b).filter (fun x => pick x = b), ?_, ?_, ?_⟩
  · intro b hb
    refine ⟨?_, ?_⟩
    · intro u hu v hv
      exact (hcov.1 b hb).1 u (Finset.mem_filter.1 hu).1 v (Finset.mem_filter.1 hv).1
    · intro u hu
      exact (hcov.1 b hb).2.1 (Finset.mem_filter.1 hu).1
  · intro x hx
    exact ⟨pick x, (hpick x hx).1, Finset.mem_filter.2 ⟨(hpick x hx).2, rfl⟩⟩
  · intro b₁ _ b₂ _ hne
    rw [Finset.disjoint_left]
    intro x h₁ h₂
    have e₁ := (Finset.mem_filter.1 h₁).2
    have e₂ := (Finset.mem_filter.1 h₂).2
    exact hne (e₁.symm.trans e₂)

/-- Dilworth's decomposition theorem: P is the disjoint union of width(P) chains. -/
theorem decomposition (P : Finset α) :
    ∃ (A : Finset α) (d : α → Finset α), MaxAntichain P A ∧
      (∀ b ∈ A, IsChainF (d b) ∧ d b ⊆ P) ∧ (∀ x ∈ P, ∃ b ∈ A, x ∈ d b) ∧
      (∀ b₁ ∈ A, ∀ b₂ ∈ A, b₁ ≠ b₂ → Disjoint (d b₁) (d b₂)) := by
  obtain ⟨A, hA⟩ := exists_maxAntichain P
  obtain ⟨c, hc⟩ := dilworth P A hA
  obtain ⟨d, hd⟩ := disjoint_cover hc
  exact ⟨A, d, hA, hd⟩

end V1.Dilworth

* Exec — the seam to the implementation
:PROPERTIES:
:header-args:lean: :tangle V1/Exec.lean
:END:

Everything above is stated on predicates and an abstract order; none of it
runs. An implementation computes: it has a finite universe of known events,
a /decidable/ order, and lists. This module is the typed seam: executable
versions of =Down=, =adopt= and =drop= over lists, each with a theorem that
its membership is exactly the model's predicate. The Dafny spike showed
this obligation cannot be skipped — a ghost order cannot be called from
compiled code — and here it is discharged in the same language as the
model, so the oracle binary in [[*Oracle]] /is/ the model.

#+begin_src lean
import V1.Worlds

namespace V1.Exec
open V1.Worlds
variable {α : Type} [PartialOrder α] [DecidableEq α] [DecidableRel (α := α) (· ≤ ·)]

/-- ↓C inside a finite universe U -/
def downImpl (U C : List α) : List α := U.filter (fun x => C.any (fun c => decide (x ≤ c)))
/-- ↑C inside U -/
def upImpl (U C : List α) : List α := U.filter (fun x => C.any (fun c => decide (c ≤ x)))
def adoptImpl (U S C : List α) : List α := S ++ (downImpl U C).filter (fun x => !S.contains x)
def dropImpl (U S C : List α) : List α := S.filter (fun x => !(upImpl U C).contains x)

theorem mem_downImpl (U C : List α) (x : α) :
    x ∈ downImpl U C ↔ x ∈ U ∧ Down (fun c => c ∈ C) x := by
  simp [downImpl, Down, List.mem_filter, List.any_eq_true]

theorem mem_upImpl (U C : List α) (x : α) :
    x ∈ upImpl U C ↔ x ∈ U ∧ Up (fun c => c ∈ C) x := by
  simp [upImpl, Up, List.mem_filter, List.any_eq_true]

/-- the implementation of adopt computes the model's adopt, inside U -/
theorem mem_adoptImpl (U S C : List α) (x : α) (hSU : ∀ y, y ∈ S → y ∈ U) :
    x ∈ adoptImpl U S C ↔ x ∈ U ∧ adopt (fun y => y ∈ S) (fun c => c ∈ C) x := by
  simp only [adoptImpl, adopt, List.mem_append, List.mem_filter, mem_downImpl]
  constructor
  · rintro (h | ⟨⟨hU, hd⟩, _⟩)
    · exact ⟨hSU x h, Or.inl h⟩
    · exact ⟨hU, Or.inr hd⟩
  · rintro ⟨hU, h | hd⟩
    · exact Or.inl h
    · by_cases hs : x ∈ S
      · exact Or.inl hs
      · exact Or.inr ⟨⟨hU, hd⟩, by simp [hs]⟩

theorem mem_dropImpl (U S C : List α) (x : α) (hSU : ∀ y, y ∈ S → y ∈ U) :
    x ∈ dropImpl U S C ↔ drop (fun y => y ∈ S) (fun c => c ∈ C) x := by
  simp only [dropImpl, drop, List.mem_filter, Bool.not_eq_eq_eq_not, Bool.not_true,
    List.contains_eq_mem, decide_eq_false_iff_not, mem_upImpl]
  constructor
  · rintro ⟨hs, hn⟩; exact ⟨hs, fun hu => hn ⟨hSU x hs, hu⟩⟩
  · rintro ⟨hs, hn⟩; exact ⟨hs, fun ⟨_, hu⟩ => hn hu⟩

end V1.Exec
#+end_src

* Check — property tests on the same definitions
:PROPERTIES:
:header-args:lean: :tangle V1/Check.lean
:END:

Plausible (Mathlib's property tester) runs on the executable functions of
[[*Exec — the seam to the implementation][Exec]], which are proven equal to the model. So a failing test here is a
failing theorem, not a drifted copy — the reason the Python and Alloy
duplicates were retired. The universe is a $3 \times 3$ grid under the
product order, a poset with real antichains; ideals are generated as
down-closures of random sets.

#+begin_src lean
import V1.Exec
import Mathlib.Order.Basic
import Mathlib.Order.Fin.Basic
import Plausible

namespace V1.Check
open V1.Exec

/-- the universe: a 3×3 grid under the product order — a poset with real antichains -/
abbrev P := Fin 3 × Fin 3

instance : DecidableRel (α := P) (· ≤ ·) :=
  fun a b => decidable_of_iff (a.1 ≤ b.1 ∧ a.2 ≤ b.2) Prod.le_def.symm

def U : List P := (List.finRange 3).flatMap (fun i => (List.finRange 3).map (fun j => (i, j)))

def ideal (A : List P) : List P := downImpl U A

def sameSet (S T : List P) : Bool := S.all (· ∈ T) && T.all (· ∈ S)

/-- 2.8 as a test: adopt back what you dropped, via the convex difference -/
def roundTrip (A B : List P) : Bool :=
  let S := ideal A
  let T := ideal (A ++ B)
  let D := T.filter (fun x => !S.contains x)
  sameSet (adoptImpl U S D) T && sameSet (dropImpl U T D) S

/-- 2.7(a) as a test, for a singleton change -/
def coverA (A : List P) (c : P) : Bool :=
  let S := ideal A
  let lhs := sameSet (dropImpl U (adoptImpl U S [c]) [c]) S
  let rhs := !S.contains c && (downImpl U [c]).all (fun x => x == c || S.contains x)
  lhs == rhs

#eval Plausible.Testable.check (∀ A B : List P, roundTrip A B = true)
#eval Plausible.Testable.check (∀ (A : List P) (c : P), coverA A c = true)

end V1.Check
#+end_src

* Oracle
:PROPERTIES:
:header-args:lean: :tangle V1/Oracle.lean

The oracle binary: reads a small JSON description of a poset and a query
and answers from the executable model. Rust (or FPL) property tests call
it for differential testing; TLC traces can be replayed through it. This
is the data seam to everything that is not Lean. The format is deliberately
tiny; it will grow with the document types.

  match args with
  | ["selftest"] =>

* Sync — the dynamic half, model-checked
:PROPERTIES:
:header-args:tla: :tangle tla/Sync.tla
:END:

Everything so far is static: what a world is, what it materialises to.
Sync is a protocol, and the object it manipulates — sets of headers in
flight over a network that reorders, duplicates and loses — is not a
structure Lean's definitions talk about. So this model is a /different
object/, and its seam to the Lean model is data: TLC traces replayed
through the oracle. The properties checked: logs only grow (I13); nobody
holds a body whose redaction they have seen (8.4); every body holder is its
origin or a recorded recipient (F2); after appends stop, logs converge
under fair delivery (I12); every honest replica eventually flags an
equivocator (6.7). The first version with unbounded loss gave a real

#+begin_src tla
------------------------------- MODULE Sync -------------------------------
(* v1/FORMAL.md, the dynamic half: gossip sync over a lossy, reordering,     *)
(* duplicating network; redaction as an event with purge-on-receipt; a serve *)
(* log that must account for every body holder (F2, 8.5); and equivocation  *)
(* detection from per-replica sequence numbers (6.7).                         *)
EXTENDS Naturals, FiniteSets, TLC

CONSTANTS Replicas, MaxSeq, Byz, MaxDrops   \* Byz ⊆ Replicas may equivocate

Ids == [org: Replicas, seq: 1..MaxSeq, c: {0, 1}]     \* c: content variant (equivocation)
Kinds == {"ins", "redact"}

VARIABLES
  log,      \* log[r]     : set of headers r holds
  body,     \* body[r]    : set of ids whose body r holds
  seq,      \* seq[r]     : next sequence number of r
  net,      \* gossip messages in flight: at most one per (from, to); reorder across pairs
  drops,    \* number of messages lost so far (bounded, so liveness is meaningful)
  served,   \* served[r]  : set of <<id, to>>: r served body of id to `to`
  flagged   \* flagged[r] : set of origins r has caught equivocating

vars == <<log, body, seq, net, drops, served, flagged>>

Header(id, kind, target) == [id |-> id, kind |-> kind, target |-> target]

Init ==
  /\ log = [r \in Replicas |-> {}]
  /\ body = [r \in Replicas |-> {}]
  /\ seq = [r \in Replicas |-> 1]
  /\ net = {}
  /\ drops = 0
  /\ served = [r \in Replicas |-> {}]
  /\ flagged = [r \in Replicas |-> {}]

RedactedAt(r) == {h.target : h \in {g \in log[r] : g.kind = "redact"}}

\* --- local actions -------------------------------------------------------
Append(r) ==
  /\ seq[r] <= MaxSeq
  /\ LET id == [org |-> r, seq |-> seq[r], c |-> 0] IN
     /\ log' = [log EXCEPT ![r] = @ \cup {Header(id, "ins", id)}]
     /\ body' = [body EXCEPT ![r] = @ \cup {id}]
  /\ seq' = [seq EXCEPT ![r] = @ + 1]
  /\ UNCHANGED <<net, drops, served, flagged>>

\* a Byzantine replica mints a second event with the same seq and other content
Equivocate(r) ==
  /\ r \in Byz
  /\ seq[r] > 1
  /\ LET id == [org |-> r, seq |-> seq[r] - 1, c |-> 1] IN
     /\ Header(id, "ins", id) \notin log[r]
     /\ log' = [log EXCEPT ![r] = @ \cup {Header(id, "ins", id)}]
     /\ body' = [body EXCEPT ![r] = @ \cup {id}]
  /\ UNCHANGED <<seq, net, drops, served, flagged>>

Redact(r, h) ==
  /\ h \in log[r] /\ h.kind = "ins"
  /\ h.id \notin RedactedAt(r)
  /\ seq[r] <= MaxSeq
  /\ LET id == [org |-> r, seq |-> seq[r], c |-> 0] IN
     log' = [log EXCEPT ![r] = @ \cup {Header(id, "redact", h.id)}]
  /\ body' = [body EXCEPT ![r] = @ \ {h.id}]      \* purge locally
  /\ seq' = [seq EXCEPT ![r] = @ + 1]
  /\ UNCHANGED <<net, drops, served, flagged>>

\* --- network --------------------------------------------------------------
Gossip(r, to) ==
  /\ r # to
  /\ ~ \E m \in net : m.from = r /\ m.to = to      \* one outstanding message per pair
  /\ LET bodiesToSend == body[r] \ RedactedAt(r) IN
     /\ net' = net \cup {[from |-> r, to |-> to, hs |-> log[r], bs |-> bodiesToSend]}
     /\ served' = [served EXCEPT ![r] = @ \cup {<<id, to>> : id \in bodiesToSend}]
  /\ UNCHANGED <<log, body, seq, drops, flagged>>

Deliver(m) ==
  /\ m \in net
  /\ LET s == m.to
         newLog == log[s] \cup m.hs
         redacted == {h.target : h \in {g \in newLog : g.kind = "redact"}}
         newBody == (body[s] \cup m.bs) \ redacted          \* purge on receipt
         equiv == {h.id.org : h \in {g \in newLog :
                     \E g2 \in newLog : g2.id.org = g.id.org /\ g2.id.seq = g.id.seq /\ g2.id # g.id}}
     IN /\ log' = [log EXCEPT ![s] = newLog]
        /\ body' = [body EXCEPT ![s] = newBody]
        /\ flagged' = [flagged EXCEPT ![s] = @ \cup equiv]
  /\ net' = net \ {m}                                    \* at-most-once; dup = re-gossip
  /\ UNCHANGED <<seq, drops, served>>

Drop(m) ==
  /\ m \in net
  /\ drops < MaxDrops
  /\ net' = net \ {m}
  /\ drops' = drops + 1
  /\ UNCHANGED <<log, body, seq, served, flagged>>

Next ==
  \/ \E r \in Replicas : Append(r) \/ Equivocate(r)
  \/ \E r \in Replicas : \E h \in log[r] : Redact(r, h)
  \/ \E r \in Replicas : \E to \in Replicas : Gossip(r, to)
  \/ \E m \in net : Deliver(m) \/ Drop(m)

Sym == Permutations(Replicas \ Byz)
Msgs == [from: Replicas, to: Replicas, hs: SUBSET [id: Ids, kind: Kinds, target: Ids], bs: SUBSET Ids]
DeliverPair(r, to) == \E m \in net : m.from = r /\ m.to = to /\ Deliver(m)
Fair == /\ \A r \in Replicas : \A to \in Replicas : WF_vars(Gossip(r, to))
        /\ \A r \in Replicas : \A to \in Replicas : WF_vars(DeliverPair(r, to))
Spec == Init /\ [][Next]_vars /\ Fair

\* --- properties ------------------------------------------------------------
TypeOK ==
  /\ \A r \in Replicas : body[r] \subseteq {h.id : h \in log[r]}
  /\ \A r \in Replicas : seq[r] \in 1..(MaxSeq + 1)

\* I13: logs only grow, whatever the network does
Monotone == [][\A r \in Replicas : log[r] \subseteq log'[r]]_vars

\* 8.4: nobody holds a body whose redaction they have seen
PurgeHonoured == \A r \in Replicas : body[r] \cap RedactedAt(r) = {}

\* F2/8.5: every holder of a body is its origin or a recorded recipient
ServeLogAccounts ==
  \A r \in Replicas : \A id \in body[r] :
    id.org = r \/ \E s \in Replicas : <<id, r>> \in served[s]

\* I12: after appends stop, logs converge (needs fairness on delivery)
Quiescent == \A r \in Replicas : seq[r] = MaxSeq + 1
Converge == <>[](Quiescent => \A r \in Replicas : \A s \in Replicas : log[r] = log[s])

\* 6.7: an equivocation is eventually caught by every honest replica
EquivocationCaught ==
  \A r \in Byz : (\E s \in Replicas : \E h \in log[s] : h.id.org = r /\ h.id.c = 1)
    ~> (\A s \in Replicas \ Byz : r \in flagged[s])

#+begin_src alloy
-- v1/FORMAL.md §6 — delegation chains, scope monotonicity, revocation.
-- Bounded relational check: can a valid event exceed its root's scope?
-- Can two logs that agree below e disagree on e's validity?

open util/ordering[Clock] as clk

sig Clock {}
sig Op {}

sig Cert {
  parent : lone Cert,          -- root has no parent
  scope  : set Op,
  expiry  : one Clock
}

-- 6.2 well-formedness, enforced as a fact (integrate refuses otherwise)
fact WellFormed {
  all c : Cert | some c.parent implies {
    c.scope in c.parent.scope
    lte[c.expiry, c.parent.expiry]
  }
  no c : Cert | c in c.^parent            -- chains are acyclic
}

sig Revocation {
  target : one Cert,
  at     : one Clock
}

sig Event {
  cert  : one Cert,
  op    : one Op,
  clock : one Clock
}

-- a log is a set of certs and revocations a peer holds
sig Log {
  certs : set Cert,
  revs  : set Revocation
}

pred chainOk[L : Log, c : Cert] {
  c in L.certs
  all d : c.^parent | d in L.certs
}

pred revokedBefore[L : Log, e : Event, c : Cert] {
  some r : L.revs | r.target = c and lt[r.at, e.clock]
}

-- 6.3
pred valid[L : Log, e : Event] {
  chainOk[L, e.cert]
  all c : e.cert + e.cert.^parent | lt[e.clock, c.expiry]
  e.op in e.cert.scope
  no c : e.cert + e.cert.^parent | revokedBefore[L, e, c]
}

fun root[c : Cert] : Cert { c.*parent - (c.*parent).parent }

-- Theorem: a valid event's op lies in the scope of the root of its chain
-- (scope monotonicity composes along the chain)
assert RootScope {
  all L : Log, e : Event | valid[L, e] implies e.op in root[e.cert].scope
}

-- 6.4: two logs that agree on e's chain and on revocations of it agree on validity
assert Locality {
  all L, L2 : Log, e : Event |
    ((e.cert + e.cert.^parent) & L.certs = (e.cert + e.cert.^parent) & L2.certs) and
    (all r : Revocation | r.target in (e.cert + e.cert.^parent) implies (r in L.revs iff r in L2.revs))
    implies (valid[L, e] iff valid[L2, e])
}

-- What if well-formedness were NOT enforced? Then escalation is possible.
-- (run this to see a counterexample: a child with a wider scope than its parent)
pred escalation {
  some c : Cert | some c.parent and not (c.scope in c.parent.scope)
}

check RootScope for 6
check Locality for 6
run escalation for 4   -- expected: no instance, because WellFormed forbids it

#+end_src

#+begin_src alloy :tangle alloy/Contraction.als
-- v1/FORMAL.md 7.6 — contracting a box of tasks. When does the coarse plan lie?
-- ready(D) = minimal elements of T \ D (leaves only, criteria ignored here).
-- Contract box B (containing its representative b) to b and compare.

sig Task {
  blockedBy : set Task
}
one sig B in Task {}                 -- the box's representative
sig Part in Task {}                  -- the box: representative plus parts
fact { B in Part }
fact Acyclic { no t : Task | t in t.^blockedBy }

-- the done-set: down-closed, box atomic
sig Done in Task {}
fact DoneIdeal { Done.blockedBy in Done }
fact BoxAtomic { Part in Done or no (Part & Done) }

fun q[t : Task] : Task { t in Part implies B else t }
fun qle : Task -> Task {              -- quotient relation: x' ≤ y' if some x ≤ y
  { u, v : Task | some x, y : Task | q[x] = u and q[y] = v and x in y.^blockedBy }
}

-- fine ready set and its image; coarse ready set computed on the quotient
fun readyFine : set Task { { t : Task - Done | no (t.blockedBy - Done) } }
fun imageReady : set Task { { u : Task | some t : readyFine | q[t] = u } }
fun qTasks : set Task { { u : Task | some t : Task | q[t] = u } }
fun qDone  : set Task { { u : Task | some t : Done | q[t] = u } }
fun readyCoarse : set Task {
  { u : qTasks - qDone | no v : qTasks - qDone | v->u in qle and v != u }
}

-- the boundary condition of 7.6: no blockedBy edge crosses the box boundary
pred noCrossEdges {
  all x : Part, y : Task - Part |
    (y in x.blockedBy implies all x2 : Part | y in x2.blockedBy) and
    (x in y.blockedBy implies all x2 : Part | x2 in y.blockedBy)
}

-- 7.6 as checked: with the boundary condition, contraction commutes with ready
assert Coherent {
  noCrossEdges implies imageReady = readyCoarse
}
check Coherent for 6

-- Outside the box the condition is not even needed (box atomicity suffices):
assert CoherentOutside {
  (imageReady - B) = (readyCoarse - B)
}
check CoherentOutside for 6

-- Inside it is: without the boundary condition, "some part is ready" and
-- "the box is ready" come apart. Ask Alloy for the counterexample.
pred incoherent { not noCrossEdges and imageReady != readyCoarse }
run incoherent for 4

* Horn — the homotopical reading (interpretation, not part of the model)
:PROPERTIES:
:header-args:agda: :tangle agda/Horn.agda
:END:

Worlds as points, patches as paths, patch laws as 2-paths (Angiuli,
Morehouse, Licata, Harper). A merge situation is a horn; a merge is a
filler; in a groupoid every horn fills, by rebasing through the inverse.
Agreement of two patches under a materialiser is a 2-cell between their
images, and a 2-cell between the patches themselves is preserved by every
materialiser — functoriality, which is ADR-0004 as a theorem. Lean has no
higher inductive types, so this lives in cubical Agda and is /not/
type-linked to the rest: it interprets the model, it does not extend it.

#+begin_src agda
{-# OPTIONS --cubical --safe --guardedness #-}
-- v1/FORMAL.md §C6 and 5.6 — the homotopical reading, in cubical Agda.
-- Worlds are points of a type; patches are paths; patch laws are 2-paths.
-- A merge situation is a horn (two patches out of one world); a merge is a
-- filler. In a groupoid every horn fills (Pijul's freely-completed category);
-- "Agree" between two patches is a 2-cell between their images under M.
module Horn where

open import Cubical.Foundations.Prelude
open import Cubical.Foundations.GroupoidLaws
open import Cubical.Data.Sigma

private variable
  ℓ : Level
  W Doc : Type ℓ

-- a horn out of a, and what it means to fill it
Filler : {a b c : W} (p : a ≡ b) (q : a ≡ c) → Type _
Filler {W = W} {b = b} {c = c} p q =
  Σ[ d ∈ W ] Σ[ r ∈ b ≡ d ] Σ[ s ∈ c ≡ d ] (p ∙ r ≡ q ∙ s)

-- every horn fills when patches are invertible: rebase q onto b via p⁻¹
fillHorn : {a b c : W} (p : a ≡ b) (q : a ≡ c) → Filler p q
fillHorn {c = c} p q = c , (sym p ∙ q) , refl , square
  where
    square : p ∙ (sym p ∙ q) ≡ q ∙ refl
    square =
      p ∙ (sym p ∙ q)   ≡⟨ assoc p (sym p) q ⟩
      (p ∙ sym p) ∙ q   ≡⟨ cong (_∙ q) (rCancel p) ⟩
      refl ∙ q          ≡⟨ sym (lUnit q) ⟩
      q                 ≡⟨ rUnit q ⟩
      q ∙ refl          ∎

-- rebase / transport (FORMAL: cherry-pick as transport): a change c at a,
-- carried along p : a ≡ b, is a change at b
rebase : {a a′ b : W} (c : a ≡ a′) (p : a ≡ b) → b ≡ a′
rebase c p = sym p ∙ c

-- 5.6: two patches between the same worlds agree under a materialiser M
-- when their images are equal as paths of documents — a 2-cell in Doc
Agree : (M : W → Doc) {a b : W} (p q : a ≡ b) → Type _
Agree M p q = cong M p ≡ cong M q

agree-refl : (M : W → Doc) {a b : W} (p : a ≡ b) → Agree M p p
agree-refl M p = refl

agree-sym : (M : W → Doc) {a b : W} (p q : a ≡ b) → Agree M p q → Agree M q p
agree-sym M p q h = sym h

agree-trans : (M : W → Doc) {a b : W} (p q r : a ≡ b)
            → Agree M p q → Agree M q r → Agree M p r
agree-trans M p q r h k = h ∙ k

-- and a 2-cell between the patches themselves is the strongest form of
-- agreement: it is preserved by every M (functoriality, ADR-0004)
agree-of-2cell : (M : W → Doc) {a b : W} (p q : a ≡ b) → p ≡ q → Agree M p q
agree-of-2cell M p q h = cong (cong M) h

#+end_src
